# Restaurant-and-billing-menu

RUN:
1. Open terminal in this folder.
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open the shown local address in your browser (usually http://127.0.0.1:5000).

Features:
- Restaurant menu
- Add items
- Quantity +/-
- Delete items
- Item-wise amount
- Total amount
- Flask backend
